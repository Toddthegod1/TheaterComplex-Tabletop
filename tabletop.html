Current prototype controls
  • Drag any displayed card or marker to reposition it anywhere on the virtual table.
  • Double-click a task card to flip between its configured front and back images.
  • Right-click a card or marker for flip, rotate, bring-to-front, and remove options.
  • Use the toolbar to add extra staff cards, task cards, black markers, and white markers.
  • “Save in Browser” stores the current board state in the local browser profile on that machine.
  • “Download Save File” creates a local JSON save file that can later be loaded through “Load Save File.”
